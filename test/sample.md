# md2pdf 테스트 문서

## 한글 텍스트 테스트

이것은 한글 테스트 문서입니다. **굵은 글씨**와 *기울임*을 지원합니다.

마크다운에서 PDF로 변환할 때, 한글이 깨지지 않고 정상적으로 표시되어야 합니다.

## 코드 블록

### Python 예제

```python
def hello(name: str) -> str:
    """인사 메시지를 반환한다."""
    return f"안녕하세요, {name}!"

if __name__ == "__main__":
    print(hello("세계"))
```

### Go 예제

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, 세계!")
}
```
